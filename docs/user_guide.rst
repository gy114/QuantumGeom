User guide
==========

QuantumGeom uses a :py:class:`~quantumGeom.Bulk` tight-binding model and a
periodic Delaunay mesh to evaluate Fermi surfaces, Berry phases, and intrinsic
anomalous Hall conductivity. The runnable examples use the two-band Weyl model
bundled with the repository.
