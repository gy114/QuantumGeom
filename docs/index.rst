QuantumGeom documentation
=======================================


QuantumGeom is a python package processing the tight-binding models generated by Wannier90.
The package calculates topological and geometric properties and their consequences in the transport of electric charge and spin.
The intrinsic anomalous Hall conductivity can be computed using Fermi-surface or Fermi-sea integration.
The package describes the topology and the geometry in k space robustly.
The Brillouin zone and Fermi surfaces can be visualized using Paraview.
The transport properties such as conductivity tensor and spin conductivity tenser are calculated.
The kernel of QuantumGeom is implemented by c++, and is parallelized using OpenMP.

Yin's group in Department of Physics, Georgetown University are maintaining the package.

More features are on the way.
